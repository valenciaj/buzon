# Organizar

## Archivar, borrar y spam

Con una conversación abierta o seleccionada:

| Acción | Botón | Atajo |
| --- | --- | --- |
| Archivar (sale de la entrada, no se borra) | Archivar | <kbd>e</kbd> |
| Mover a la papelera | Papelera | <kbd>#</kbd> |
| Marcar como spam | Spam | <kbd>!</kbd> |
| Destacar | Estrella | <kbd>s</kbd> |
| Marcar como leído / no leído | | <kbd>I</kbd> / <kbd>U</kbd> |
| Mover a una carpeta | Mover | |

Los cambios se hacen también en tu servidor de correo, así que los verás igual en el móvil o en cualquier otra app.

## Buscar

Escribe en el buscador (o pulsa <kbd>/</kbd>). Buzón busca en el remitente, los destinatarios, el asunto y el texto de todos tus correos. Puedes afinar con:

| Escribe | Para encontrar |
| --- | --- |
| `de:ana` | correos de Ana |
| `para:equipo@empresa.es` | correos enviados a esa dirección |
| `asunto:factura` | la palabra en el asunto |
| `tiene:adjunto` | correos con adjuntos |
| `es:noleido` / `es:destacado` | correos sin leer / destacados |
| `etiqueta:facturas` | con esa etiqueta |
| `en:enviados` | en esa carpeta (entrada, enviados, archivo, spam, papelera…) |
| `antes:2026-01-01` / `después:2025-12-01` | por fecha |

También valen en inglés (`from:`, `has:attachment`…). Se pueden combinar: `de:ana tiene:adjunto presupuesto`.

## Etiquetas

Las etiquetas son como carpetas, pero una conversación puede tener varias. Créalas en **Ajustes › Etiquetas y filtros** o desde el botón **Etiquetar** de una conversación. Aparecen en la barra lateral con su color.

Las etiquetas son de Buzón: no cambian nada en tu servidor de correo.

## Filtros

Un filtro actúa solo sobre el correo nuevo que llega a la entrada. Por ejemplo: «si el asunto contiene *factura*, ponle la etiqueta *Facturas* y márcalo como leído».

Créalos en **Ajustes › Etiquetas y filtros**. Cada filtro tiene condiciones (de, para, asunto o texto contiene…) y acciones (etiquetar, marcar como leído, destacar, mover a una carpeta). Se aplican en orden.

## Contactos

Tus contactos se guardan solos cuando escribes a alguien. En **Contactos** puedes añadirlos a mano, editarlos, escribirles o importar un archivo `.vcf` de otra app.
