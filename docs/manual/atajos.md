# Atajos de teclado

Pulsa <kbd>?</kbd> en Buzón, o elige **Atajos de teclado** en el menú lateral, para ver esta lista. Los atajos no funcionan mientras escribes en un campo de texto.

## Moverse

| Tecla | Acción |
| --- | --- |
| <kbd>j</kbd> o <kbd>↓</kbd> | Siguiente conversación |
| <kbd>k</kbd> o <kbd>↑</kbd> | Conversación anterior |
| <kbd>o</kbd> o <kbd>Intro</kbd> | Abrir |
| <kbd>u</kbd> o <kbd>Esc</kbd> | Volver a la lista |
| <kbd>/</kbd> | Buscar |
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Paleta de órdenes |
| <kbd>g</kbd> y luego <kbd>i</kbd> | Ir a Entrada (o Principal) |
| <kbd>g</kbd> y luego <kbd>t</kbd> | Ir a Hoy |
| <kbd>g</kbd> y luego <kbd>s</kbd> | Ir a Enviados |
| <kbd>g</kbd> y luego <kbd>d</kbd> | Ir a Borradores |
| <kbd>g</kbd> y luego <kbd>a</kbd> | Ir a Archivo |

## Actuar

| Tecla | Acción |
| --- | --- |
| <kbd>c</kbd> | Redactar |
| <kbd>r</kbd> | Responder |
| <kbd>a</kbd> | Responder a todos |
| <kbd>f</kbd> | Reenviar |
| <kbd>e</kbd> | Archivar |
| <kbd>#</kbd> | Papelera |
| <kbd>!</kbd> | Spam |
| <kbd>s</kbd> | Destacar |
| <kbd>I</kbd> | Marcar como leído |
| <kbd>U</kbd> | Marcar como no leído |
| <kbd>x</kbd> | Seleccionar |
| <kbd>l</kbd> | Responder luego |
| <kbd>p</kbd> | Apartar |
| <kbd>b</kbd> | Posponer hasta mañana |
| <kbd>?</kbd> | Ver los atajos |
