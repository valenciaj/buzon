# Keyboard shortcuts

Press <kbd>?</kbd> in Buzón, or choose **Keyboard shortcuts** in the side menu, to see this list. Shortcuts don't work while you're typing in a text field.

## Moving around

| Key | Action |
| --- | --- |
| <kbd>j</kbd> or <kbd>↓</kbd> | Next conversation |
| <kbd>k</kbd> or <kbd>↑</kbd> | Previous conversation |
| <kbd>o</kbd> or <kbd>Enter</kbd> | Open |
| <kbd>u</kbd> or <kbd>Esc</kbd> | Back to the list |
| <kbd>/</kbd> | Search |
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Command palette |
| <kbd>g</kbd> then <kbd>i</kbd> | Go to Inbox (or Main) |
| <kbd>g</kbd> then <kbd>t</kbd> | Go to Today |
| <kbd>g</kbd> then <kbd>s</kbd> | Go to Sent |
| <kbd>g</kbd> then <kbd>d</kbd> | Go to Drafts |
| <kbd>g</kbd> then <kbd>a</kbd> | Go to Archive |

## Actions

| Key | Action |
| --- | --- |
| <kbd>c</kbd> | Compose |
| <kbd>r</kbd> | Reply |
| <kbd>a</kbd> | Reply all |
| <kbd>f</kbd> | Forward |
| <kbd>e</kbd> | Archive |
| <kbd>#</kbd> | Trash |
| <kbd>!</kbd> | Spam |
| <kbd>s</kbd> | Star |
| <kbd>I</kbd> | Mark as read |
| <kbd>U</kbd> | Mark as unread |
| <kbd>x</kbd> | Select |
| <kbd>l</kbd> | Reply later |
| <kbd>p</kbd> | Set aside |
| <kbd>b</kbd> | Snooze until tomorrow |
| <kbd>?</kbd> | Show shortcuts |
