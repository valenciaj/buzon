# Organizing

## Archive, delete and spam

With a conversation open or selected:

| Action | Button | Shortcut |
| --- | --- | --- |
| Archive (leaves the inbox, isn't deleted) | Archive | <kbd>e</kbd> |
| Move to trash | Trash | <kbd>#</kbd> |
| Mark as spam | Spam | <kbd>!</kbd> |
| Star | Star | <kbd>s</kbd> |
| Mark as read / unread | | <kbd>I</kbd> / <kbd>U</kbd> |
| Move to a folder | Move | |

Changes are also made on your mail server, so you'll see the same thing on your phone or any other app.

## Search

Type in the search box (or press <kbd>/</kbd>). Buzón searches the sender, recipients, subject and text of all your email. You can narrow it down with:

| Type | To find |
| --- | --- |
| `from:ana` | email from Ana |
| `to:team@company.com` | email sent to that address |
| `subject:invoice` | the word in the subject |
| `has:attachment` | email with attachments |
| `is:unread` / `is:starred` | unread / starred email |
| `label:invoices` | with that label |
| `in:sent` | in that folder (inbox, sent, archive, spam, trash…) |
| `before:2026-01-01` / `after:2025-12-01` | by date |

The Spanish forms work too (`de:`, `tiene:adjunto`…). They can be combined: `from:ana has:attachment quote`.

## Labels

Labels are like folders, but a conversation can have several. Create them in **Settings › Labels and filters** or from a conversation's **Labels** button. They show up in the sidebar with their color.

Labels belong to Buzón: they don't change anything on your mail server.

## Filters

A filter acts only on new mail arriving in the inbox. For example: "if the subject contains *invoice*, label it *Invoices* and mark it as read".

Create them in **Settings › Labels and filters**. Each filter has conditions (from, to, subject or text contains…) and actions (label, mark as read, star, move to a folder). They're applied in order.

## Contacts

Your contacts are saved automatically when you write to someone. In **Contacts** you can add them by hand, edit them, write to them or import a `.vcf` file from another app.
