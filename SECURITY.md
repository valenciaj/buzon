# Seguridad / Security

[Español](#español) · [English](#english)

## Español

Buzón guarda contraseñas y tokens de cuentas de correo, así que cualquier fallo de seguridad nos importa.

### Cómo informar de una vulnerabilidad

**No abras un issue público.** Usa el botón [**Report a vulnerability**](https://github.com/valenciaj/buzon/security/advisories/new) de la pestaña *Security* del repositorio. El aviso solo lo verán los mantenedores.

Incluye, si puedes:

- qué parte está afectada (API, sincronización IMAP, saneado del HTML, webhooks, instalación…);
- los pasos para reproducirlo o una prueba de concepto;
- el impacto que crees que tiene;
- la versión o el commit con el que lo has probado.

Intentaremos responder en unos días. Cuando haya una corrección, publicaremos el aviso y te daremos crédito si quieres.

### Versiones con soporte

Solo se corrigen fallos en la última versión publicada y en la rama `main`.

## English

Buzón stores passwords and tokens for email accounts, so we take any security issue seriously.

### Reporting a vulnerability

**Please don't open a public issue.** Use the [**Report a vulnerability**](https://github.com/valenciaj/buzon/security/advisories/new) button in the repository's *Security* tab. Only the maintainers will see the report.

If you can, include:

- the affected area (API, IMAP sync, HTML sanitizing, webhooks, installation…);
- steps to reproduce or a proof of concept;
- the impact you expect;
- the version or commit you tested.

We'll try to reply within a few days. Once a fix is ready we'll publish the advisory and credit you if you'd like.

### Supported versions

Only the latest release and the `main` branch receive security fixes.
